# آماده‌سازی داده گفتار درس

این ابزار یک صف محلی از متن‌های فارسی و نوشته‌های تصویری موجود در پروژه می‌سازد. خروجی دیتاست آماده آموزش گفتار نیست: برای هر قطعه باید حق استفاده، متن محاوره‌ای، تلفظ، صدای ضبط‌شده با اجازه گوینده و هم‌ترازی بررسی شوند. هیچ آوا، گوینده یا صدایی به طور خودکار ساخته یا تایید نمی‌شود.

```sh
python3 deep-learning/scripts/prepare_speech_text.py \
  --source-dir deep-learning/content/translations/spring-2026 \
  --output /tmp/course-speech-review.jsonl
```

فایل خروجی نباید بدون بررسی حقوق متن و صدا منتشر شود. فایل موجود بازنویسی نمی‌شود. هر رکورد شناسه جلسه و صفحه، هش متن نمایشی و هش متن مرجع صفحه، و برچسب جداگانه آموزش، اعتبارسنجی یا آزمون دارد. متن‌های کاملا یکسان فقط یک بار نگه داشته می‌شوند. این جداسازی جلوی تکرار دقیق را می‌گیرد؛ شباهت متن‌ها، نشت گوینده و هم‌پوشانی معنایی همچنان نیازمند بازبینی هستند.

پیش از آموزش، مجموعه آزمون باید ثابت بماند و شامل اصطلاحات، اعداد، عبارت‌های دوزبانه، کسره اضافه و گفت‌وگوی طبیعی باشد. مکث و آواهای گفتاری باید بر پایه صدای واقعی و بازبینی شنیداری ثبت شوند؛ درج مصنوعی «ام» و نشانه‌های تلفظ به تنهایی کیفیت صدا را ثابت نمی‌کند. ارزیابی نهایی باید علاوه بر آزمون فنی، شامل شنیدن کور و ثبت خطاهای تلفظ و طبیعی بودن باشد.

## منابع عمومی اولیه

- [Mana-TTS](https://huggingface.co/datasets/MahtaFetrat/Mana-TTS): برچسب CC0 در کارت داده؛ revision `698f7f7bfe7a8fc665e9c4c0ca9eea7e0d49f64f`. مجموعه تک‌گوینده است و به تنهایی گفت‌وگوی دو نفره یا اصطلاحات این درس را تضمین نمی‌کند.
- [Audio8-TTS-Persian](https://huggingface.co/ArminRahimi/Audio8-TTS-Persian): برچسب Apache-2.0 در کارت مدل؛ revision `bcca4112db62fccaf733772226d4f9931a088a0a`. نامزد ارزیابی است، نه مدل پذیرفته‌شده. کد سفارشی و شرایط مدل پایه باید پیش از اجرا و آموزش بررسی شوند.

متادیتای این دو منبع در ۲۰۲۶-۱۱-۰۸ ساعت ۰۷:۰۶ UTC بررسی شد. شرایط گوینده، داده و مدل را برای نسخه مورد استفاده جداگانه بررسی کن؛ برچسب مخزن جایگزین تایید کیفیت یا اجازه استفاده از صدای شخص نیست.

برای بررسی قالب داده بدون دریافت مجموعه کامل، دستور زیر یک نمونه صوت و متن عمومی را در پوشه جدید ذخیره می‌کند؛ سقف این ابزار ۱۰ نمونه است. فایل manifest شناسه نسخه مشاهده‌شده، هش WAV، متن و نرخ نمونه‌برداری را ثبت می‌کند. این فایل‌ها داده آموزشی تاییدشده یا خروجی مدل نیستند.

```sh
python3 deep-learning/scripts/fetch_mana_sample.py --output /tmp/mana-audit --limit 1
```

نسخه مخزن هنگام دریافت از API مشاهده می‌شود؛ سرویس ردیف‌ها بازگرداندن همان نسخه خاص را تضمین نمی‌کند. پیش از هر استفاده آموزشی باید اصالت فایل‌های دریافت‌شده و انطباقشان با نسخه انتخابی مستقل بررسی شود.

برای بررسی فایل‌های صوتی بازبینی‌شده، دستور زیر مسیر و هش WAV، وجود متن گفتار، گوینده، وضعیت بازبینی تلفظ و حقوق، و نبود تکرار دقیق صوت و متن میان بخش‌ها را کنترل می‌کند:

```sh
python3 deep-learning/scripts/validate_speech_manifest.py reviewed.jsonl --audio-root /path/to/audio
```

در هر رکورد تاییدشده فیلدهای `spoken_text_fa`، `speaker_id`، `rights`، `audio_path`، `audio_sha256`، `split`، `review_status` و `pronunciation_reviewed` لازم هستند. این بررسی ماشینی جای شنیدن، بررسی حقوق یا داوری علمی را نمی‌گیرد.
