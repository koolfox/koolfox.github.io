# Spring 2026 page delivery audit

The 21 sessions contain 1,303 source pages. The build creates separate PDFs for 1,275 pages. The 28 page numbers listed in `data/metadata/spring-2026-page-fallbacks.json` use the unchanged complete source PDF; the reader states this when one of those pages is opened. Once that session PDF is cached, later fallback pages in the same session can reuse it. Generated page bytes and the source PDF are checked by SHA-256 before use or persistent storage.

The fallback list is deliberately conservative. An exploratory PDF.js comparison rendered the full PDF and the extracted PDF at scale 0.5 with fonts disabled, checked their dimensions and annotation destinations, and repeated flagged cases with independent browser contexts and equal waits. The comparison used pypdf 6.21.4 for the published page files; a further sample used PDFium 5.14.0. Some pixel differences varied across runs and a subset remained after retesting. They are not proof of a visible defect or of its cause. Conversely, a matching pixel sample does not establish visual, translation, accessibility or scientific acceptance, and other viewports, browser engines, font settings and annotations need their own review.

All 21 source PDFs were checked for internal PDF link destinations. None were found; the build refuses to split a source if such destinations are introduced, rather than silently breaking navigation. External annotation targets were compared during the pixel experiment and tested on linked pages in the browser.

Visited PDF pages can be reused from validated browser storage during a loaded session. A full offline reload is not guaranteed: reader assets and session metadata still require network access or an independently available browser cache. The browser may deny or evict storage; an unvisited page is not promised offline. Non-fallback pages fetch their own PDF, while translation data still loads per session. The downloadable ZIP deliberately includes whole source PDFs and its reader uses those files, avoiding duplication of all page PDFs in the ZIP. It works from a local server without an internet connection.

Measurements from a local November 2026 build: source PDFs total about 77 MiB; independent page files about 236 MiB before exclusions; project artifact about 592 MiB; Spring 2026 ZIP about 91 MiB; whole deep-learning build about 11 seconds on that machine. Actual CI, site totals, bandwidth, browser quota, and device performance can differ. Mobile behavior was tested using Chromium's iPhone 13 emulation, not a physical iPhone or Safari.
