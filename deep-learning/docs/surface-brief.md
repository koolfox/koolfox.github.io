## Direction contract

computed example, their own prediction, and an experiment. Five calendars stay
distinct; shared explanations are reused with explicit source mappings.

OWN-WORLD: Local Arad, Persian RTL, the existing quiet blue and neutral light
palette. Plain reading columns, visible section navigation, technical expressions
isolated LTR. Source references occupy the margin, not the prose column.

STORY: Choose a term, open a lesson, understand one mechanism, predict a result,
run the corresponding small experiment, explain the result, then continue.

FIRST VIEWPORT: A compact course masthead and breadcrumb; the lesson title and
opening in the reading column, source/page navigation in a narrower desktop
margin. Mobile puts the source summary before the lesson and keeps controls in
normal flow. The hub presents five semester rows with concrete topic differences.

FORM: The user-pinned semester → lesson → experiment structure; no visual-world
replacement. Inherited design, readable content first, progressive laboratory
loading. The signature interaction is a prediction followed by a real Python step
whose weights, boundary and measured loss update together.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
