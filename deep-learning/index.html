python3 -m pip install numpy

این موارد از مرجع بهار ۲۰۲۶ دانشگاه کلرادو آمده‌اند، نه تکلیف استاد شما یا موعدهای شخصی تو.

  • طرح پروژه: ۳ تا ۴ صفحه، بدون شمارش منابع.
  • ارائه: پیوند ویدیوی ۴ دقیقه‌ای و پوستر PDF در یک فایل ZIP.
  • ارزیابی همتا: بررسی فردی ۱۵ تا ۲۰ پروژه تخصیص‌یافته.
