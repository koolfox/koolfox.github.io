این کد را چطور بخوانم؟

int عدد صحیح، float اعشاری و str متن است. def یک تابع تعریف می‌کند؛ ورودی‌های داخل پرانتز به آن داده می‌شوند. return نتیجه را برمی‌گرداند و for یک کار را برای چند مقدار تکرار می‌کند.

کنترل‌ها تنظیمات اجرای فعلی‌اند؛ CONFIG تنظیمات آغازینِ پس از اجرای کد است. با «تنظیمات فعلی به کد» آن‌ها را منتقل کن. ویرایش تا زدن «اجرای کد» روی نمودار اثر ندارد؛ اجرای کد، آزمایش را از ابتدا می‌سازد.

هنگام تغییر تابع فعال‌سازی، مشتق و زیان را هم سازگار نگه دار. نام کنترل‌ها و راهنمای شکل‌ها، قواعد نسخهٔ اولیه را شرح می‌دهند؛ با تغییر فرمول، معنای خروجی را از کد فعلی بخوان. نمایش عددها گرد شده و محاسبات اعشاری دقت محدود دارند. اگر حلقه پایان نیافت، «توقف اجرای پایتون» محیط را می‌بندد.
