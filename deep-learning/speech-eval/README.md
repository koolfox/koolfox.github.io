# آزمون شنیداری گفتار درس

بیست جمله مستقل از اصطلاحات درس، با عدد، واژه انگلیسی و کسره در متن مخصوص گفتار. متن نمایشی و متن گفتار جدا هستند؛ نوشتار آوایی به معنی تایید تلفظ نیست. این مجموعه کیفیت صدا یا درستی علمی را تایید نمیکند.

با Python 3.13 و `piper-tts==1.8.0` و فایلهای محلی مدل و config تولید کنید:

```sh
python generate.py --models /path/to/models --output /tmp/course-listening-eval
```

پوشه خروجی باید خالی یا وجود نداشته باشد. فایل `blind/index.html` را به شنونده بدهید و `answer-key-private.json` را تا پایان داوری پنهان نگه دارید. ترتیب جمله ها و جای A/B با بذر ثابت 2606 تعیین میشود؛ A در همه جمله ها یک صدا نیست. مقداردهی تصادفی داخلی موتور صوت ممکن است باعث تفاوت موج در تولید مجدد شود. هش مدل و config در کلید ثبت میشود.

برای هر نمونه طبیعی بودن، وضوح و تلفظ را از ۱ تا ۵ ثبت کنید و خطاهای مهم را یادداشت کنید. در محیط یکسان و بدون آگاهی از مدل ها گوش کنید. بعد از ثبت نظر، نتایج را با کلید مقایسه کنید. فایلهای صوتی، کلید، امتیازها و داده شخصی را در مخزن ثبت نکنید. پیش از انتشار صدا، مجوز هر مدل و داده آموزشی، و بازبینی علمی و شنیداری را جداگانه بررسی کنید.
