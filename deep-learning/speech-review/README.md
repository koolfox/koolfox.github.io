# بازبینی محلی صدا و متن HamBam

ابزار از فایل EAF و صدای همنام، برش های WAV و صف CSV میسازد. متن آوانویسی رومی منبع است و تطبیق صدا، متن، تلفظ و کسره پیش از گوش دادن «بررسی نشده» ثبت میشود. هر ردیف زمان آغاز، زمان پایان annotation و پایان واقعی برش را ثبت میکند؛ اگر برچسب از مدت فایل طولانی تر باشد، برش به انتهای فایل محدود میشود و اختلاف آن آشکار میماند. زمان ها در سطح گفتار هستند، نه واژه.

منبع [HamBam v3](https://fd-repo.uni-bamberg.de/records/v80bg-h0243) با [مجوز CC BY 4.0](https://fd-repo.uni-bamberg.de/records/v80bg-h0243/files/LICENCE.txt?download=1) منتشر شده است؛ در هر استفاده بعدی انتساب مناسب را حفظ کنید.

نیازمندی: Python 3.11 یا جدیدتر، ffmpeg و ffprobe. خروجی باید مسیری تازه بیرون از مخزن باشد:

```sh
python3 eaf_review.py --eaf /path/to/annotation.eaf --audio /path/to/audio.mp3 --output /tmp/hambam-review --limit 3
```

`review.csv` صف بازبینی و `provenance.json` هش فایل های ورودی و منبع را دارد. صوت، annotation، خروجی و نظر شنونده را عمومی یا در گیت ثبت نکنید. پیش از استفاده، همنام بودن و انطباق دقیق فایل ها و مجوزشان را مستقلا بررسی کنید. ابزار تطبیق و کیفیت صدا را تایید نمیکند.
