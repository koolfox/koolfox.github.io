# Research agent workflow

The user requested agents for evidence checking and incremental public progress. Delegate independent tasks; avoid concurrent edits to the same artifact.

| Role | Responsibility | Reviewable output |
| --- | --- | --- |
| Literature researcher | Verify publisher/PubMed metadata, methods, access and evidence limits | Persian review and `data/metadata/literature.json` |
| Dataset auditor | Inspect official sample metadata, drugs, pairing, donors and actual gene availability | Dataset catalog and `data/metadata/datasets.json` |
| Structure/graphics developer | Implement numerical analysis and render experimental coordinates using a shared selection policy | Python, Three.js scene, figures and provenance |
| Independent reviewer | Check scientific invariants, numerical edge cases, browser behavior and the final render | Prioritized findings and validation evidence |
| Coordinator | Reconcile contradictory counts, maintain protocol, run checks and publish authorized increments | Tested commits, PRs and verified Pages builds |

Before accepting a result, verify its primary sources and whether it reports a proposed, downloaded or actually analyzed dataset. The 2025 spatial preprint and the final 2026 paper must not be confused. Record observed code defects before fixes; report precisely what the final checks establish.

Use the repository skill for domain constraints. Do not turn agent summaries into scientific results without artifacts. Continuous Pages updates in this session are authorized; no future schedule or autonomous background process has been configured.
