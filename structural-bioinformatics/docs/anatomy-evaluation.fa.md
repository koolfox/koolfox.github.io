# ارزیابی عملی Anatomy برای پژوهش درسی

تاریخ آزمون: `2026-10-13`. [Anatomy](https://skills.wheresryan.sh/anatomy#install) یک skill و کیت تصویرسازی ایزومتریک است: مفاهیم فنی را با دستگاه‌های مکانیکی و رفتار قابل مشاهده توضیح می‌دهد. برای پروژهٔ ما، کاربرد آن می‌تواند توضیح مرحله‌ای یک مفهوم باشد؛ ساختار پروتئین باید همچنان از مختصات آزمایشگاهی نمایش داده شود.

## نصب با منشأ مشخص

[مخزن رسمی](https://github.com/wheresryan22/anatomy) و [مجوز MIT](https://github.com/wheresryan22/anatomy/blob/e6600ffc4e8e6620eeb45bf49bcdbd5e4b84163f/LICENSE) بررسی شدند. قبل از اجرا، `SKILL.md`، کیت هندسه، helper تولید صفحه و اسکریپت نمونه خوانده شدند. نصب با helper رسمی `skill-installer` در پوشهٔ کاربر `~/.codex/skills/anatomy` انجام شد؛ skill قبلی وجود نداشت و چیزی بازنویسی نشد.

```sh
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo wheresryan22/anatomy --path . --name anatomy \
  --ref e6600ffc4e8e6620eeb45bf49bcdbd5e4b84163f
```

این دستور به helper نصب موجود در Codex نیاز دارد. commit ثابت به‌جای HEAD متغیر ثبت شد. محیط آزمون: macOS روی Apple Silicon، Node.js `24.14.0` و Chromium همراه Playwright. طبق [راهنمای skill](https://github.com/wheresryan22/anatomy/blob/e6600ffc4e8e6620eeb45bf49bcdbd5e4b84163f/SKILL.md)، Node.js `20.10+` و Chrome/Chromium لازم‌اند.

## آزمون واقعی و نتیجه

یک کپی جداگانه در `/private/tmp` ساخته شد؛ مثال رسمی کوچک `dial-indicator` در هر دو تم اجرا شد:

```sh
node examples/dial-indicator/build.mjs
node examples/dial-indicator/build.mjs --light
```

پروجکشن ایزومتریک با مقدار محاسبه‌شدهٔ مستقل مقایسه شد؛ خروجی استوانه چهار tone و مختصات متناهی داشت. صفحات ساخته‌شده در مرورگر باز شدند و تصاویر هر چهار حالت دیده شدند.

| تم / عرض | تصویر و SVG | تغییر با صفحه‌کلید | کاهش حرکت / اسکرول افقی |
|---|---|---|---|
| تیره / `1440 px` | `338` مسیر SVG، بدون خطای JavaScript | End: بلوک ۳ / `10.0 px`؛ Home: بلوک ۱ / `18.0 px` | مقدار پس از سکون ثابت؛ بدون سرریز |
| تیره / `390 px` | همان نمونه، متناسب با موبایل | موفق | ثابت؛ بدون سرریز |
| روشن / `1440 px` | همان نمونه، تم روشن | موفق | ثابت؛ بدون سرریز |
| روشن / `390 px` | همان نمونه، متناسب با موبایل | موفق | ثابت؛ بدون سرریز |

واحد `px` مربوط به مدل آموزشی مثال است؛ هیچ فاصلهٔ مولکولی یا اندازه‌گیری زیستی از این نمونه برداشت نمی‌شود. این یک آزمون راه‌اندازی و تعامل بود؛ ممیزی کامل برخورد اجزای مکانیکی، 3D beta، همهٔ مثال‌ها یا دسترس‌پذیری جامع انجام نشده است. خطوط خاکستری ظریف نمونه، برای کاربرد آموزشی روی موبایل به بررسی بیشتر خوانایی نیاز دارند.

## تصمیم برای این پروژه

- **Three.js:** دیدن مختصات واقعی TNF، Fab و TOP2A–DNA و انتخاب زنجیره‌ها.
- **ManimGX:** ویدئوی ساختاری قابل ارائه؛ رندر `3WD5` اجرا و frame واقعی آن بررسی شد.
- **Anatomy:** ابزار توضیح مفهومی اختیاری؛ پارسر PDB و موتور پیش‌بینی اتصال یا ساختار RNA ندارد.
- **Mermaid و KaTeX:** زنجیرهٔ استدلال با سطح شواهد مشخص و نمایش فرمول‌های روش؛ اصل داده و استناد همچنان در متن می‌ماند.

دستگاه مکانیکی مثال در صفحهٔ پژوهش منتشر نمی‌شود، چون ارتباط مولکولی را نشان نمی‌دهد. برای تصاویر پژوهش، [قواعد منشأ و caption ساختاری](visualization-tools.fa.md) را رعایت کنید و فرضیهٔ آدالیموماب–TOP2A را از سازوکار مستقیم آدالیموماب–TNF جدا بنویسید.
