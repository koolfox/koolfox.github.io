# پروتکل داکینگ: اعتبارسنجی با پاسخی که از قبل معلوم است

> **جای این سند در مسیر:** [نقشهٔ واحد پروژه](course-guide.fa.md) · [جلسات درس](course-sessions.fa.md) · [پروتکل RNA-seq](rnaseq-research-plan.fa.md) · [اصلاح‌ها و موارد باز](comprehensive-review.fa.md).

**وضعیت: اجراشده روی یک نمونهٔ کنترل‌شده.** این سند روش داکینگ را روی کمپلکسی می‌آزماید که پاسخ آن از قبل در ساختار کریستال ثبت شده است. هدف، سنجش درستی خط لولهٔ کار است، نه جست‌وجوی مهارکنندهٔ تازه. هیچ‌چیز در این سند دربارهٔ آدالیموماب، TNF یا TOP2A اندازه‌گیری نمی‌کند.

## چرا داکینگ را با پاسخ معلوم شروع می‌کنیم

داکینگ یعنی پیدا کردن جایگاه و حالتِ اتصال یک مولکول به یک گیرنده. اگر اولین بار سراغ یک جفتِ تازه برویم، هر pose برگشتی می‌تواند یا یک جایگاه درست باشد یا یک تصادفِ خوش‌ظاهر؛ از خودِ خروجی نمی‌شود فهمید کدام. راه استاندارد، **بازداکینگ (redocking)** است: همان گیرنده و همان لیگاندی که در ساختار کریستال با هم نشسته‌اند دوباره داک می‌شوند و pose برگشتی با pose کریستال سنجیده می‌شود. اگر روش درست باشد، pose کریستال بازتولید می‌شود؛ اگر بازتولید نشود، مشکل از روش است، نه از سیستم زیستی.

در این پروژه سه دروازه تعریف شده است و هر سه باید جداگانه گزارش شوند:

1. **بازتولید pose:** RMSD سنگین‌اتمی pose اول نسبت به pose کریستال حداکثر **2.0 Å**.
2. **بازتولید جایگاه:** فسفر لیگاندِ برگشتی در همان حفرهٔ کلسیمی بنشیند، با اختلاف حداکثر 1 Å نسبت به ساختار کریستال.
3. **جدا کردن جایگاه درست از جایگاه غلط:** امتیاز موتور در جایگاه واقعی دست‌کم **1.0 kcal/mol** بهتر از جایگاه کنترل باشد.

دروازهٔ سوم همان چیزی است که یک امتیاز خوب را از یک نشانهٔ واقعی جدا می‌کند. اگر امتیاز نتواند جایگاه درست را از جایگاه غلط جدا کند، آن امتیاز دلیلِ اتصال نیست.

## سامانهٔ آزمون: 1B09

| ویژگی | مقدار |
| --- | --- |
| شناسه | [1B09](https://www.rcsb.org/structure/1B09)، پروتئین واکنشی C (CRP) با فسفوکولین |
| روش و تفکیک‌پذیری | پراش پرتو X، 2.5 Å |
| گیرنده | پنج‌تایی CRP با زنجیره‌های `A` تا `E` و ده یون کلسیم |
| لیگاند | فسفوکولین با کد `PC`، یک نسخه در هر زیرواحد (۵۵ اتم سنگین در مجموع) |
| جایگاه مرجع | فسفوکولین زنجیرهٔ `A`، باقی‌ماندهٔ 500 |
| چرا این نمونه | پاسخ کریستالی معلوم، لیگاند کوچک و انعطاف‌پذیر، جیب وابسته به کلسیم، و زمان اجرای کمتر از ده ثانیه |

انتخاب این نمونه از منطق تدریس می‌آید، نه از پروژهٔ آدالیموماب: برای یادگیری داکینگِ پروتئین–مولکولِ کوچک، یک کمپلکس با پاسخ قطعی لازم است. فسفوکولین یک فسفات زویتریونی است که با کلسیم هماهنگ می‌شود؛ همین باعث می‌شود کنترلِ جایگاهِ غلط حتماً باید از هر یون کلسیم هم دور باشد.

## محیط اجرا

داکینگ از محیط اصلی پروژه جداست، چون موتور و ابزارهای آماده‌سازی ساختار در آن نیستند. نسخه‌ها پین شده‌اند تا نتیجه بازتولید شود:

```bash
conda create -y -n tnf-docking -c conda-forge python=3.12 vina=1.2.7
conda run -n tnf-docking pip install meeko==0.8.0 rdkit gemmi scipy requests
```

| جزء | نسخه |
| --- | --- |
| موتور | AutoDock Vina 1.2.7، تابع امتیاز `vina` |
| آماده‌سازی گیرنده و لیگاند | Meeko 0.8.0 (`mk_prepare_receptor.py`، `mk_prepare_ligand.py`) |
| شیمی و RMSD | RDKit 2026.09.1، NumPy، SciPy |
| پایتون | 3.12 |

## گام‌ها، با فرمان دقیق

هر سه اسکریپت در `structural-bioinformatics/docking/` هستند و خروجی میانی آن‌ها در `results/docking/1b09/` (در مخزن نگه داشته نمی‌شود) نوشته می‌شود.

**۱. آماده‌سازی ورودی‌ها.** گیرنده از روی همان فایل `1B09.pdb` ثبت‌شده با هش ساخته می‌شود: پنج زنجیرهٔ پروتئینی و ده یون کلسیم می‌مانند، آب‌ها و هر پنج فسفوکولین حذف می‌شوند. لیگاندِ داک‌شده مدل ایده‌آل مؤلفهٔ شیمیایی از [RCSB](https://files.rcsb.org/ligands/download/PC_ideal.sdf) است و pose مرجع، همان فسفوکولین ثبت‌شده در زنجیرهٔ `A` است. جعبهٔ جست‌وجو مرکز آن بر سرِ مرکز جرم لیگاند کریستال و به اندازهٔ 20 Å در هر سه جهت است.

```bash
conda run -n tnf-docking python structural-bioinformatics/docking/prepare_redock.py
conda run -n tnf-docking mk_prepare_receptor.py \
  --read_pdb results/docking/1b09/receptor.pdb -o results/docking/1b09/receptor \
  --write_pdbqt results/docking/1b09/receptor.pdbqt
conda run -n tnf-docking mk_prepare_ligand.py \
  -i results/docking/1b09/ligand_ideal.sdf -o results/docking/1b09/ligand.pdbqt
```

**۲. داکینگ و کنترل.** همان لیگاند، همان گیرنده، همان پارامترها؛ فقط مرکز جعبه فرق می‌کند. جعبهٔ کنترل روی نقطه‌ای از پروتئین می‌افتد که از هر فسفوکولین دست‌کم 12 Å و از هر یون کلسیم دست‌کم 6 Å دور است: نه لیگاندی دارد و نه جایگاه فلزی.

```bash
conda run -n tnf-docking python structural-bioinformatics/docking/run_vina.py
```

پارامترها: exhaustiveness برابر 32، seed برابر 42، چهار هسته، ۲۰ pose درخواستی. seed ثابت است تا اجرای دوباره همان نتیجه را بدهد.

**۳. سنجش.** RMSD سنگین‌اتمی poseها نسبت به pose کریستال، **بدون هم‌راستاسازی** (دو pose در دستگاه مختصات ساختار سنجیده می‌شوند) و با اجازهٔ جابه‌جایی فقط اکسیژن‌های هم‌ارز فسفات محاسبه می‌شود. فاصلهٔ فسفر هر pose تا نزدیک‌ترین یون کلسیم هم ثبت می‌شود.

```bash
conda run -n tnf-docking python structural-bioinformatics/docking/score_pose.py
```

## تفسیر: چه چیزی ثابت شد و چه چیزی نشد

**خط لوله درست کار می‌کند.** pose اول با 1.155 Å از pose کریستال بازتولید شد و فسفر آن در همان حفرهٔ کلسیمی نشست (3.26 Å در برابر 3.05 Å کریستال). پنج pose اول همگی زیر 1.2 Å هستند و poseهای بعدی از هم فاصله می‌گیرند. یعنی روش آماده‌سازی، جعبه، پارامترها و سنجش با هم سازگارند.

**امتیاز، جایگاه را تشخیص نداد.** در همان گیرنده، جعبهٔ کنترل **0.36 kcal/mol بهتر** امتیاز گرفت. یعنی اگر فقط به امتیاز نگاه می‌کردیم، جایگاه کنترل را به‌عنوان بهترین جایگاه انتخاب می‌کردیم. این یک نتیجهٔ منفیِ واقعی و آموزنده است: امتیاز Vina یک تابع رتبه‌بندی است، نه انرژی آزاد اتصال، و روی یک لیگاندِ باردار در جیبِ کلسیم، امتیازِ یک سطحِ بی‌لیگاند می‌تواند به‌سادگی بهتر باشد. به همین دلیل در هر ارائهٔ داکینگ، کنترلِ جایگاهِ غلط کنار نتیجهٔ اصلی گزارش می‌شود، نه اینکه امتیاز به‌تنهایی نقل شود.

**آنچه این سند ثابت نمی‌کند:** اینکه داکینگ برای آدالیموماب–TNF کار می‌کند؛ اینکه امتیازِ منفی یعنی اتصال قوی‌تر؛ اینکه هر pose با RMSD کم الزاماً درست است؛ و اینکه فسفوکولین و CRP نمایندهٔ TNF و آدالیموماب‌اند. این‌ها پرسش‌های جدا هستند.

## گام بعدی: نیمهٔ پروتئین–پروتئین

بخش «Docking پروتئین و پروتئین» سرفصل هنوز اجرا نشده است. ورودی‌های آن از همین پروژه آماده‌اند: گیرنده، سه‌تایی بازسازی‌شدهٔ TNF از روی گروه فضایی `3WD5`، و Fab آدالیموماب با نقشهٔ اپی‌توپ (۳۶۵ تماس، ۳۱ درصد سهم زیرواحد همسایه). مسیر پیشنهادی:

1. **دروازهٔ اول، بازداکینگ Fab:** گیرنده، سه‌تایی TNF است و لیگاندِ انعطاف‌پذیر، Fab. معیار موفقیت، بازیابی همان رابط است: درصد جفت‌های باقی‌ماندهٔ اپی‌توپ در pose اول و RMSD رابط. پیش از آن، یک کنترلِ لازم است: Fab باید جابه‌جا شود و دوباره داک شود تا دیده شود رابط تصادفی بازتولید نمی‌شود.
2. **مرز روش:** امتیاز Vina برای پروتئین–پروتئین کالیبره نشده است. اگر Fab در جایگاه خودش برنگردد، این یک نتیجهٔ منفی دربارهٔ همین ابزار است، نه دربارهٔ پروژه؛ در آن صورت باید سراغ روش‌های تخصصی‌تر مثل HADDOCK رفت و آن را هم با همان دروازهٔ بازداکینگ سنجید.
3. **زمان:** یک اجرای Fab روی سه‌تایی به‌مراتب سنگین‌تر از این نمونهٔ کوچک است و باید جداگانه زمان‌سنجی شود.

تا وقتی این دروازه اجرا نشده، موضوع «Docking پروتئین و پروتئین» در [برنامهٔ هفته‌به‌هفته](weekly-plan.fa.md) با وضعیت «هنوز اجرا نشده» می‌ماند.
