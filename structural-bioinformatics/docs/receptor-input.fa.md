# بررسی اولیهٔ فایل PDB کاربر

ساختار هدف را از یک منبع معتبر بگیرید یا فایل خودتان را مشخص کنید. شناسهٔ زنجیره در PDB همان شناسهٔ نویسندگان است؛ پیش از اجرا باید بدانید کدام زنجیره و کدام شکل زیستی برای پرسش شما مناسب است. این دستور فایل را تغییر نمی‌دهد:

```bash
uv run --project structural-bioinformatics python -m peptide_lab.receptor_input \
  --pdb /path/to/target.pdb --chain A
```

گزارش JSON هش فایل، زنجیره و باقی‌مانده‌ها را نشان می‌دهد. ابزار یک مدل و زنجیرهٔ پروتئینی از ۲۰ آمینواسید استاندارد را بررسی می‌کند. زنجیرهٔ غایب، مختصات نامتناهی، اتم ستون فقرات گمشده، اشغال نامشخص یا صفر، حالت جایگزین، آب، لیگاند و باقی‌ماندهٔ تغییر‌یافته در زنجیرهٔ انتخابی باعث توقف می‌شود و باید جداگانه بررسی شود. برای مثال فایل پاک‌سازی‌شدهٔ `assets/course/gromacs/1ubq-protein.pdb` با زنجیرهٔ A، ۷۶ باقی‌مانده دارد؛ این فقط کنترل خواندن ورودی است.

**عبور از این غربال به معنای آماده‌بودن برای داکینگ نیست.** پیوستگی و اتم‌های جانبی، ساختار زیستی، پروتون‌گذاری، یون‌ها، لیگاندها، دی‌سولفیدها، حل حالت‌های جایگزین، حلقه‌های گمشده و محل جعبه به بررسی نیاز دارند. برای Vina باید گیرنده به PDBQT مناسب تبدیل شود. مستندات [آماده‌سازی گیرندهٔ Meeko](https://meeko.readthedocs.io/en/develop/rec_overview.html) و [راهنمای داکینگ پایه](https://meeko.readthedocs.io/en/develop/tutorial1.html) مراحل و محدودیت‌ها را شرح می‌دهند. این ابزار هنوز PDB دلخواه را به‌طور خودکار برای داکینگ پارامترگذاری نمی‌کند.
