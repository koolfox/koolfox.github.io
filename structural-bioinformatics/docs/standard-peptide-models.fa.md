# ساخت مدل اولیه از ۲۰ آمینواسید استاندارد

پیش‌تر ابزار شمارش و تولید FASTA همهٔ ۲۰ حرف استاندارد را می‌پذیرفت؛ اکنون ابزار جداگانهٔ زیر می‌تواند برای حداکثر ۲۰ توالی انتخاب‌شده، هرکدام با طول ۱ تا ۱۲، یک فایل SDF دارای مختصات اولیه بسازد. برای اجرا محیط `docking/environment.yml` لازم است:

```bash
conda run -n tnf-docking python structural-bioinformatics/scripts/build_peptide_models.py \
  --sequence AC --sequence AR --sequence AW \
  --output-dir structural-bioinformatics/results/peptides-01
```

از RDKit برای ساخت زنجیرهٔ خطی L، نمونه‌گیری ETKDGv3 با seed ثابت و یک بهینه‌سازی MMFF94 استفاده می‌شود. فرض‌های بار در گزارش ثبت می‌شوند: انتهای N مثبت و C منفی، Asp/Glu منفی، Lys/Arg مثبت، هیستیدین خنثی و سیستئین احیاشده. حالت‌های دیگر بار، پیوند دی‌سولفیدی، حلقوی‌بودن و تغییر انتها ساخته نمی‌شوند. برنامه برای شکست ساخت یا همگرا نشدن بهینه‌سازی وضعیت خطا ثبت می‌کند و پوشهٔ قبلی را بازنویسی نمی‌کند.

در آزمون محلی، دی‌پپتیدهای `A` به‌علاوهٔ هر یک از ۲۰ حرف استاندارد ساخته شدند و بار و برچسب دست‌سانی کربن آلفا در توپولوژی کنترل شد. این نمونه‌برداری، بررسی کامل شیمی سه‌بعدی، پیش‌بینی ساختار در محلول یا تأیید اتصال نیست. مدل‌ها هنوز به داکینگ خودکار روی فایل PDB کاربر وصل نشده‌اند. [مستندات RDKit دربارهٔ ساخت از توالی](https://rdkit.org/docs/source/rdkit.Chem.rdmolfiles.html) روش ورودی و حالت L را توضیح می‌دهد.
