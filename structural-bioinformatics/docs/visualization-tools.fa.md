تاریخ بررسی: 2026-10-13. هدف، دیدن ساختار آزمایشگاهی و توضیح ارتباط اجزای آن است. نمایش سه‌بعدی به‌تنهایی آزمون اتصال، اثربخشی دارو یا پاسخ بالینی نیست.

در اجرای فعلی، Python دادهٔ ساختاری را انتخاب و تحلیل می‌کند و Three.js همان مختصات را از JSON نمایش می‌دهد. ManimGX برای ویدئوی قابل ارائه، Mermaid برای زنجیرهٔ استدلال و KaTeX برای فرمول مناسب‌اند. شکل مکانیکی Anatomy باید به‌وضوح «مدل آموزشی» نامیده شود؛ شکل Cα، نمودار تماس و طرح مفهومی سه نوع شاهد متفاوت‌اند.

خوانندهٔ Markdown از `markdown-it 15.0.2` استفاده می‌کند. نسخه، مجوز و SHA256 فایل‌های خواننده، Mermaid و KaTeX در `data/metadata/reading-vendor.json` ثبت شده‌اند؛ نتیجه و محدودهٔ آزمون نمایش واقعی اسناد در `VALIDATION.md` مخزن آمده است.

## نمونهٔ واقعی ساخته‌شده

[3WD5 در RCSB](https://www.rcsb.org/structure/3WD5) کمپلکس TNFα با **قطعهٔ Fab آدالیموماب**، حاصل پراش پرتو X با وضوح `3.10 Å` است. فایل استفاده‌شده یک زنجیرهٔ TNF با شناسهٔ نویسندهٔ `A` و زنجیره‌های Fab با شناسه‌های `H` و `L` دارد. این نمایش، TNF سه‌زیرواحدی یا آنتی‌بادی کامل IgG را بازسازی نمی‌کند.

خروجی [اسکریپت در مخزن](https://github.com/koolfox/koolfox.github.io/blob/main/structural-bioinformatics/scripts/animate_binding.py):

- `results/animations/tnf-adalimumab-3wd5.mp4`: ویدئوی H.264، ابعاد `1280×720`، نرخ `30 fps`، مدت فایل `10.733333 s`، حجم نسخهٔ بررسی‌شده `1,615,743` بایت. نسخهٔ عمومی در `assets/tnf-adalimumab.mp4` قرار دارد.
- `results/animations/tnf-adalimumab-3wd5.json`: منشأ، SHA256 ورودی، پارامترها و نسخهٔ موتور.
- `results/animations/tnf-adalimumab-3wd5.storyboard.png`: نماهای انتهای مراحل، حاصل دستور inspect.

SHA256 ویدئوی بازتولیدشده با رنگ‌های ثابت زنجیره‌ها و حذف occupancy صفر:

```text
af600b4f7b7586b8404dc6acc9587cc6ee2116207417f88e44eeaa732c30b35f
```

اتم‌های Cα با occupancy مثبت: `A=152`، `H=210` و `L=211`؛ در مجموع `573` اتم. شش رکورد Cα با occupancy صفر (`H41`، `H135`، `H142`، `H198`، `L212` و `L213`) نمایش داده نمی‌شوند. انتخاب شامل اولین مدل، رکوردهای `ATOM` و alternate location با بیشترین occupancy است؛ در تساوی، اولویت با blank، سپس `A` و سپس ترتیب الفبایی است. از اتصال نقاطی با فاصلهٔ بیش از `4.5 Å` خودداری می‌شود. نمایش Cα جای ribbon مبتنی بر ساختار ثانویه یا سطح مولکولی را نمی‌گیرد.

معنای رنگ‌ها در شکل‌ها ثابت است: `A`، پروتومر TNF، سبزآبی؛ `H`، زنجیرهٔ سنگین Fab، نارنجی؛ `L`، زنجیرهٔ سبک Fab، آبی. برای خوانایی روی زمینهٔ تیرهٔ ویدئو، رنگ‌های `#5DCBC1`، `#F6B16B` و `#9EAFF5` به‌کار می‌روند. این نقش‌ها در `assets/animation-provenance.json` ثبت شده‌اند. یک frame واقعی MP4 در زمان `5.5 s` رمزگشایی و دیده شد؛ بررسی فقط از روی poster نبود.

مرکزدهی، چرخش صحیح PCA و مقیاس یکنواخت فقط قاب نمایش را تعیین می‌کنند. مختصات نسبی زنجیره‌ها ثابت است؛ حرکت دوربین و آشکارشدن زنجیره‌ها، مسیر اتصال دارو یا دینامیک مولکولی نیست. در بررسی عددی، خطای فاصلهٔ نقاط مجاور پس از تبدیل نمایشی کمتر از `1.4e-14 Å` بود.

## بازتولید از ریشهٔ پوشهٔ پروژه

محیط رندر را از محیط تحلیل جدا نگه دارید. [مستندات رسمی ManimGX](https://manimgx.academa.ai/user-guide/quickstart/) Python 3.13 یا 3.14 را پشتیبانی می‌کند و encoding و typesetting را در بسته دارد.

```sh
uv venv --python 3.13 .venv-animation
uv pip install --python .venv-animation/bin/python manimgx==0.1.1 numpy==2.5.4
mkdir -p data/raw/structures results/animations
curl -fL https://files.rcsb.org/download/3WD5.pdb -o data/raw/structures/3WD5.pdb
.venv-animation/bin/manimgx inspect scripts/animate_binding.py TNFAdalimumabComplex -o results/animations/tnf-adalimumab-3wd5.storyboard.png
.venv-animation/bin/python scripts/animate_binding.py
```

برای مسیر متفاوت از `--pdb` و `--output` و برای کیفیت از `--width`، `--height` و `--fps` استفاده کنید. اسکریپت مستقل از working directory مسیر پیش‌فرض را نسبت به پوشهٔ پروژه پیدا می‌کند. فایل رسمی دانلودشده در این اجرا SHA256 زیر را داشت:

```text
fae6eee1b06b8cba0a466280dbc32563efaa54ec639afd921cb610d17debd216
```

محیط واقعاً آزمایش‌شده در `/private/tmp/tnf-manimgx-check`: macOS `26.5.1`، معماری `arm64`، CPython `3.13.12`، uv `0.11.2`، ManimGX `0.1.1`، NumPy `2.5.4` و Pillow `12.3.0`. محیط اصلی پروژه تغییر نکرد. هم inspect و هم رندر موفق بودند؛ storyboard و یک frame رمزگشایی‌شدهٔ MP4 دیده شدند. موتور برای صحنهٔ سه‌بعدی **بررسی خودکار چیدمان را اجرا نمی‌کند**؛ بررسی بصری لازم است. تکرار frame ثابت باعث می‌شود تعداد نمونه‌های encoded با `timeline_frames` برابر نباشد.

## قواعد شکل قابل استناد

در caption هر شکل، PDB ID، مدل/assembly، زنجیره‌ها، نمایش، وضوح و ابزار را ثبت کنید. برای نشان‌دادن interface، معیار فاصلهٔ اتم‌های سنگین و cutoff را جداگانه محاسبه و مستند کنید؛ آستانهٔ `4.5 Å` این اسکریپت فقط برای پیوستگی trace است. دادهٔ مفقود را به شکل مشاهده‌شده تبدیل نکنید. نتیجهٔ ساختاری و نمودار CRP یا شاخص بیماری را تنها با منبع داده و روش آماری مشخص به یکدیگر مرتبط کنید.
