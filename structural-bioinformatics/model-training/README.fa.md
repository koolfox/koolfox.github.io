# محدوده مجوز آموزش مدل BioOps

فایل [مجوز اختصاصی](LICENSE) شرایط موقت استفاده از مواد اختصاصی آموزش مدل در این پوشه و متن طرح ارزیابی Qwen را مشخص میکند. دیدن فایلهای عمومی ممکن است، اما استفاده و بازنشر مواد مشمول، جز در موارد مجاز طبق قانون یا شرایط سرویس میزبان، به اجازه کتبی صاحبان حقوق نیاز دارد.

کد و داده اختصاصی آموزش، تنظیمات آزمایش، وزنهای تنظیم شده و خروجیهای آموزشی که قرار است تابع این مجوز باشند باید با مشخص بودن صاحب حقوق و شرایط داده، در همین محدوده یا یک محل دارای کنترل دسترسی مشخص نگهداری شوند. نام بردن از یک فایل در این متن به معنی انتشار یا وجود آن نیست.

این مجوز شرایط مدل پایه Qwen، ابزارها، داده های دیگران یا حقوقی را که پیشتر به شکل معتبر واگذار شده اند تغییر نمیدهد. پس از انتشار مقاله نیز تغییر مجوز خودکار نیست و به تصمیم جداگانه صاحبان حقوق نیاز دارد. دسترسی عمومی به مخزن و حق fork طبق شرایط GitHub همچنان برقرار است.
